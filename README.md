# MCA Machine Learning Lab Programs

This repository contains the laboratory programs, experiments, and assignments completed as part of the **Machine Learning Lab** course in the **Master of Computer Applications (MCA)** curriculum.

## Repository Structure
ML-Lab/
│
├── LAB01/
├── LAB02/
├── LAB03/
├── LAB04
└── ...


Each lab folder contains:
- Source code
- Input datasetS
- Brief description of the experiment

## Technologies Used

- Python 3.x
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
